# @md/cf-page

An opinionated, HTML-close web-framework for creating Cloudflare Pages.

## [Documentation](https://cf-page.mdressler.dev)

## Why not any of the big frameworks?

I love the simplicity of creating websites using HTML, CSS, and JavaScript and
find Cloudflare Pages an awesome solution for hosting small "static" sites.

However, tooling like TypeScript or Tailwind are incredible successors to the
original web.

This framework is my attempt at merging the simplicity of the "original web"
with the powers of modern tooling, some great utilities such as minification and
cache-busting, all with the simplicity of Cloudflare Pages.
